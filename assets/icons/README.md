# 喜茶风稚拙简笔画图标集 · 使用规范 v1.0

一套圆润稚拙、绿色主调的手绘简笔画图标，适用于本站全部页面的小图标场景。

## 一、设计语言

| 维度 | 规范 |
|---|---|
| 风格 | 稚拙手绘简笔画：圆润流畅的线条、简化形态、适度几何化，允许轻微"不完美"的手绘感 |
| 网格 | 48×48 viewBox，笔画居于安全区内（边距 ≥ 6px） |
| 线条 | stroke-width 2.2–2.6，linecap / linejoin 均为 round（圆头圆角） |
| 主色 | 墨黑 `#1A1A1A`（所有描边与实心图形） |
| 填充 | 白色 `#FFFFFF`（信封、圆牌、头像、旗面、绶带等面状元素），配墨黑描边 |
| 中性色 | 页面浅灰底为 `#F4F1EA`；图标不使用彩色 |
| 禁忌 | 不用尖锐折线、不用渐变/阴影、不混用品牌彩色、不拉伸变形 |

## 二、文件清单

```
assets/icons/
├── user.svg        人物（个人信息 / 关于我）
├── flag.svg        旗帜（政治面貌 / 党员身份）
├── mail.svg        信封（邮箱）
├── phone.svg       电话听筒（联系电话）
├── medal.svg       奖章绶带（奖项 / 奖学金 / 荣誉）
├── image.svg       画框（截图占位 / 图片待补充）
├── arrow-left.svg  左箭头（返回 / 后退）
├── spark.svg       四角星（点缀 / 闪光装饰）
└── png/            同名 PNG：64 / 128 / 256 px 三档（@1x/@2x/@3x）
```

- **SVG 为源文件**，网站引用优先使用 SVG（矢量，任意分辨率清晰）。
- PNG 用于不支持 SVG 的场景（如 PPT、Word、社交平台上传），三档尺寸覆盖普通屏到 Retina。

## 三、尺寸规范

| 使用场景 | 建议显示尺寸 |
|---|---|
| 圆形衬底图标（.ico / .ci / .medal，衬底圆 34–38px） | 17–20px |
| 气泡内四角星（.spark） | 12px |
| 返回按钮箭头（.back-home） | 14px |
| 页脚返回链接箭头 | 15px |
| 截图占位大图标（.slot-icon） | 30px |

- 图标必须**等比缩放**，宽高一致，禁止单向拉伸。
- 图标在圆形/圆角衬底中居中，视觉留白约为衬底直径的 40–50%。

## 四、页面引用方式

```html
<!-- 标准用法：内联尺寸，随文字颜色无关（绿色已烘焙进 SVG） -->
<img src="assets/icons/mail.svg" alt="" style="width:20px;height:20px;display:block"/>
```

- 装饰性图标 `alt=""`；有语义的图标（如奖章列表）可用 `alt="奖章"`。
- 相对路径：所有页面位于站点根目录，统一写 `assets/icons/xxx.svg`。
- 新增图标后，运行 `node tools/export-icons.mjs` 可重新导出全部 PNG；
  全站批量替换可参考 `tools/apply-icons.ps1`。

## 五、新增图标的要求

1. 复制任一现有 SVG 作为模板，保持 48×48 网格与相同描边参数；
2. 只用两种颜色：`#1A1A1A`（描边/实心）/ `#FFFFFF`（面状填充）；
3. 造型优先"少笔画、一眼识别"，笔画端点圆润；
4. 同时导出 PNG 并在本 README 文件清单中登记。
